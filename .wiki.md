# Project Summary
Logistics web application with localized EN/SR UI that supports onboarding, authentication, and the main entry page, keeping consistent header branding via language-specific logo assets.

# Project Module Description
- `Layout` (`app/frontend/src/components/Layout.tsx`): Shared application chrome; renders the header brand and applies fixed-size logo container + display-only sizing to keep EN/SR visually identical.
- `i18n` (`app/frontend/src/lib/i18n.ts`): Selects the active language/brand variant that determines which logo asset is shown.
- Pages:
  - `Index` (`app/frontend/src/pages/Index.tsx`): Main entry page; uses the same header/logo container sizing behavior.
  - `Login` (`app/frontend/src/pages/Login.tsx`): Authentication page; uses the same header/logo container sizing behavior.
  - `Onboarding` (`app/frontend/src/pages/Onboarding.tsx`): Onboarding flow page; aligns header/logo container sizing for consistent appearance.

# Directory Tree
- `app/frontend/`
  - `src/`
    - `components/`
      - `Layout.tsx`: App-wide header branding wrapper with fixed logo container sizing.
    - `lib/`
      - `i18n.ts`: Language selection and brand-variant resolution for the logo.
    - `pages/`
      - `Index.tsx`: Landing page using the shared header/logo sizing.
      - `Login.tsx`: Login page using the shared header/logo sizing.
      - `Onboarding.tsx`: Onboarding page with aligned header/logo sizing.
  - `public/`
    - `assets/`
      - `cargontainer-logo-en.png`: English logo asset (tagline inside image).
      - `cargontainer-logo-sr.png`: Serbian logo asset (tagline inside image).
- `uploads/`
  - `image-1.png`: Uploaded logo source for SR variant workflow.
  - `image-2.png`: Uploaded logo source for EN variant workflow.

# File Description Inventory
- `app/frontend/src/components/Layout.tsx`: Fixes header logo display sizing using a fixed container (EN/SR identical), removes spacing that caused shrink/offset, and ensures image fits without distortion.
- `app/frontend/src/pages/Index.tsx`: Ensures the landing page header uses the corrected fixed-size logo container.
- `app/frontend/src/pages/Login.tsx`: Ensures the login page header uses the corrected fixed-size logo container.
- `app/frontend/src/pages/Onboarding.tsx`: Aligns onboarding header/logo sizing with the same fixed-size container behavior.

# Technology Stack
- TypeScript + React (frontend)
- pnpm for lint/build
- EN/SR localized branding via image assets

# Usage
- Install dependencies: `pnpm install`
- Run lint: `pnpm run lint`
- Build: `pnpm run build`
